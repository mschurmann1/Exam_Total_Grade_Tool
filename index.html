Exam Total Export

Load one Canvas gradebook export with the written exam scores already entered, and one WeBWorK totals file with the practice problem set. The tool fills the practice problems column on a 10 point scale and the exam total column (Etotal = Written + Practice Problems + Extra Credit). Files are read in your browser and never uploaded anywhere.

Add your files

Set up Canvas before exporting
  1. Create the columns used for each exam, for example Exam 1 Written, Exam 1 Practice Problems (10 points) and Exam 1 Etotal. An extra credit or attendance column for the exam is optional.
  2. Enter the written exam scores, and any extra credit, in Canvas as usual.
  3. So nothing is counted twice, put the Written, Practice Problems and extra credit columns in an assignment group worth 0%, and put the Etotal columns in the exam group.

Column names do not need to match these examples. The tool suggests columns by exam number and lets you change any of them.

How to get the Canvas gradebook export
  1. In your Canvas course, open Grades from the course navigation.
  2. Click Export at the top right of the Gradebook.
  3. Choose Export Entire Gradebook. The .csv file downloads to your computer.

Export after the written scores are entered, so the tool can add them into Etotal. Students excused in Canvas appear as EX, and those cells are kept as EX.

How to get the WeBWorK totals file
  1. Click on Scoring Tools.
  2. Select the practice problem set for the exam. More than one set can be selected; you choose which one to use below.
  3. Make sure Pad fields is unchecked.
  4. Click the Score selected set(s) and save to: button.
  5. Download the file ending in totals.csv and add it in the WeBWorK totals file box below.

The totals file can include every section of the course. Only students in your Canvas export are used.

Drop a file onto a box or click it to browse. Each file is identified by its contents, so a file placed in the wrong box is sorted automatically.

Embedded Math Gym TAs

Embedded TAs are listed as students in Canvas. Marking them here skips them: their Canvas cells are left untouched, and they do not appear in the preview, the warnings or the report. Your choices are remembered in this browser (by abc123 login only).

Choose the exam columns

Columns are suggested by the exam number in the WeBWorK set name. Check each one; your choices are remembered for each set.

Add a Canvas export and a WeBWorK totals file to choose the columns.

How the scores are calculated

Practice Problems: the student's WeBWorK total for the set is divided by the set's total value and multiplied by the scale (10 by default), rounded to two decimals. For example, 18 out of 20 in WeBWorK gives 9.

Etotal: the written score from Canvas, plus the practice problem points, plus every extra credit column you check. Blank or EX extra credit counts as 0. For example, 90 written + 10 practice problems + 3 attendance gives 103.

Etotal is left untouched when the written score is blank or EX in Canvas, so a missing exam never turns into a low total. It is also left untouched when the student has no practice problem score (no WeBWorK record, no total in the file, or a 0 held back because the 0 option is off).

Students are matched by the SIS Login ID in Canvas and the login ID in WeBWorK. A student with no matching login is matched by full name only when exactly one WeBWorK student has that name. Any Practice Problems or Etotal cell already marked EX in Canvas stays EX.

Download

The file keeps every row and column of your Canvas export, with only the Practice Problems and Etotal columns filled in. Import it through Canvas Gradebook, Import.

The report lists every student whose Practice Problems or Etotal cell was not filled, with the reason and what to do. It opens in Excel and is for your records only, not for importing into Canvas.
